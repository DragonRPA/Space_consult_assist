## 2. 기술 원리

### 2.1 WASAPI Loopback 캡처란?

**WASAPI (Windows Audio Session API)**는 Windows Vista 이후 Microsoft가 제공하는 저지연 오디오 API입니다.

WASAPI에는 **Loopback 모드**가 있으며, 이 모드를 사용하면 특정 오디오 출력 장치로 내보내지는 디지털 오디오 데이터를 `입력 스트림`처럼 가로채서 읽을 수 있습니다.

```
일반 녹음:  [마이크] ──▶ [WASAPI Input] ──▶ 애플리케이션
루프백:    [출력 장치] ──▶ [WASAPI Loopback] ──▶ 애플리케이션
```

### 2.2 볼륨과 루프백의 관계

| 상황 | 루프백 데이터 |
|---|---|
| Windows 볼륨 100% | 정상 오디오 데이터 수신 ✅ |
| Windows 볼륨 50% | 50% 감쇄된 오디오 수신 ✅ (STT 가능) |
| Windows 볼륨 0% / 음소거 | 완전한 무음(0) 수신 ❌ (STT 불가) |
| 물리 스피커 전원 OFF | 정상 오디오 수신 ✅ (디지털 단계에서 캡처) |

> **핵심**: WASAPI Loopback은 **Windows 마스터 볼륨 적용 이후**의 신호를 캡처합니다.
> VB-CABLE의 볼륨은 100%로 유지하고, 상담사 청취 볼륨은 물리 헤드셋 볼륨 노브로 조절합니다.

### 2.3 VB-CABLE을 사용하는 이유

**문제**: 소프트폰 오디오를 물리 스피커(헤드셋)에 직접 출력하면서 동시에 루프백 캡처를 하면, 상담사가 볼륨을 0으로 내렸을 때 STT가 작동하지 않습니다.

**해결**: VB-CABLE(가상 오디오 장치)을 Windows 기본 출력으로 설정합니다.

- 소프트폰 오디오 → **VB-CABLE** (가상 장치, 볼륨 100% 유지)
- VB-CABLE → **WASAPI Loopback** → Python → Whisper (STT)
- VB-CABLE → **"이 장치로 듣기"** → 물리 헤드셋 (상담사 청취)

상담사는 물리 헤드셋 볼륨 노브로 청취 볼륨을 조절하고, VB-CABLE의 Windows 볼륨은 항상 100%로 유지합니다.

### 2.4 청크 기반 실시간 처리

Python 백엔드는 VB-CABLE Output을 **고정 시간 단위(청크)**로 잘라서 처리합니다.

```
[VB-CABLE 오디오 스트림]
  ├── [0.0s ~ 2.0s] → Whisper 추론 → "안녕하세요 고객님" → WebSocket 전송
  ├── [2.0s ~ 4.0s] → Whisper 추론 → "네 문의 사항이" → WebSocket 전송
  ├── [4.0s ~ 6.0s] → 무음 감지 → 스킵 (VAD)
  └── [6.0s ~ 8.0s] → Whisper 추론 → "어떻게 되시나요" → WebSocket 전송
```

| 청크 크기 | 반응 속도 | 오인식 위험 | 권장 사용 상황 |
|---|---|---|---|
| 0.5초 | 매우 빠름 | 높음 (단어 1~2개 수준) | 비교 테스트용 |
| 1초 | 빠름 | 중간 | 비교 테스트용 |
| 2초 | 보통 | 낮음 | **실제 운영 권장** |

### 2.5 전체 처리 파이프라인

```
[소프트폰 오디오]
        ↓ 48kHz Stereo Float32
[VB-CABLE 캡처] (Python soundcard 라이브러리, WASAPI 백엔드)
        ↓ n초 청크
[에너지 기반 VAD] → 무음이면 스킵 (RMS < 0.004)
        ↓ 유음 청크
[리샘플링] 48kHz → 16kHz, Stereo → Mono (scipy.signal.resample_poly)
        ↓ 16kHz Mono Float32
[Faster-Whisper Large-v3-Turbo] (CUDA, RTX 5080 GPU)
        ↓ 세그먼트 [{text, start, end}, ...]
[FastAPI WebSocket] ws://127.0.0.1:8000/api/v1/stt/ws
        ↓ JSON {"text": "...", "start": 0.0, "end": 1.8}
[Space Advisor 브라우저] → 실시간 자막 표출
```

## 3. VB-CABLE 설치

### 3.1 다운로드 및 설치

1. **https://vb-audio.com/Cable/** 접속
2. `VBCABLE_Driver_Pack43.zip` 다운로드
3. 압축 해제
4. `VBCABLE_Setup_x64.exe` **우클릭 → 관리자 권한으로 실행**
5. `Install Driver` 클릭
6. 설치 완료 후 PC 재시작 권장

## 4. Windows 레거시 제어판 설정 방법

> **경로**: 작업표시줄 우하단 🔊 스피커 아이콘 우클릭 → **소리 설정** → 맨 아래 **"추가 소리 설정"**
> (또는 제어판 → 하드웨어 및 소리 → 소리)

### 4.1 재생 탭 — VB-CABLE을 기본 출력 장치로 설정

```
소리 창 → [재생] 탭
        ↓
"CABLE Input (VB-Audio Virtual Cable)" 우클릭
        ↓
"기본 장치로 설정(D)" 클릭
        ↓
초록색 체크마크(✅) 확인
        ↓
[확인]
```

> 이 설정 이후 모든 PC 오디오(소프트폰 포함)가 VB-CABLE로 출력됩니다.
> 물리 스피커로 소리가 나지 않더라도 아래 4.2 설정으로 해결됩니다.

### 4.2 녹음 탭 — "이 장치로 듣기" 설정 (상담사 청취 복원)

```
소리 창 → [녹음] 탭
        ↓
"CABLE Output (VB-Audio Virtual Cable)" 더블클릭
        (또는 선택 후 [속성(P)] 클릭)
        ↓
속성 창 → [수신 대기] 탭
        ↓
☑ "이 장치로 듣기" 체크박스 ON
        ↓
"이 장치로 재생:" 드롭다운
        → 상담사가 사용하는 헤드셋 또는 스피커 선택
          예) 헤드폰 (Realtek Audio)
              스피커 (Realtek Audio)
        ↓
[적용] → [확인]
```

> 헤드셋 교체 시 이 드롭다운 설정만 변경하면 됩니다.

### 4.3 설정 완료 확인

| 항목 | 확인 방법 |
|---|---|
| VB-CABLE 기본 장치 설정 | 재생 탭에서 CABLE Input에 ✅ 초록 체크 |
| 상담사 청취 복원 | 브라우저에서 동영상 재생 시 헤드셋으로 소리 들림 |
| STT 작동 | Space Advisor 헤더 [루프백 STT 시작] 클릭 후 통화 시 자막 표출 |

## 5. Space Advisor 루프백 STT 사용 방법

### 5.1 사전 조건 체크리스트

- [ ] VB-CABLE 설치 완료
- [ ] CABLE Input이 Windows 기본 재생 장치로 설정됨 (재생 탭)
- [ ] "이 장치로 듣기" → 헤드셋으로 연결됨 (녹음 탭)
- [ ] 로컬 GPU 백엔드 실행 중 (`start_backend_stt.bat` 더블클릭)

### 5.2 사용 순서

```
1. start_backend_stt.bat 더블클릭
   → 콘솔 창에 "Uvicorn running on http://127.0.0.1:8000" 확인

2. Space Advisor 브라우저 새로고침
   → 헤더에서 [Faster-Whisper (GPU)] 버튼 클릭
   → 초록 점 + "GPU 대기 중" 배지 확인

3. 청크 크기 선택: [0.5초] [1초] [2초] 중 선택
   → 기본값 2초 권장

4. [루프백 STT 시작] 클릭
   → 배지가 빨간 점 + "루프백 실시간 수신 중"으로 변경됨

5. 소프트폰으로 통화 수신
   → 상담 자막이 선택한 청크 단위로 화면에 순차 표출됨

6. 통화 종료 후 [루프백 중지] 클릭
```

### 5.3 문제 해결

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| 자막이 전혀 안 나옴 | 루프백 STT 미시작 | 헤더에서 [루프백 STT 시작] 클릭 |
| 자막이 나오다가 멈춤 | 무음 구간 VAD 스킵 | 정상 동작 — 발화 구간에만 자막 표출 |
| 헤드셋에서 소리 안 들림 | "이 장치로 듣기" 미설정 | 4.2 설정 재확인 |
| "GPU 대기 중" 배지 없음 | 백엔드 미실행 | `start_backend_stt.bat` 실행 |
| 엉뚱한 텍스트 반복 출력 | 청크 너무 짧음 | 청크를 2초로 변경 |
| 볼륨 0에서 자막 없음 | WASAPI Loopback 구조상 정상 | VB-CABLE 볼륨 100% 유지, 물리 헤드셋 볼륨만 조절 |
| [루프백 STT 시작] 버튼 없음 | Faster-Whisper (GPU) 미선택 또는 백엔드 오프라인 | 엔진 선택 및 백엔드 실행 확인 |
